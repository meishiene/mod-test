参数说明与判定规则先选生成方式（仅文生视频 / 带参考图 / 带参考视频 / 两者都带），面板只展示该方式用得到的参数。走火山方舟异步任务面：先提交任务拿 task id，再轮询到终态（queued → running → succeeded / failed）；成功后视频下载归档，报告里给出可直接打开的链接。参考视频只有视频地址会随任务提交（该接口只接受 URL），本地上传的视频文件仅归档留痕。参数取值域由后端下发、前端只做一次预校验，服务端仍会二次校验；提示词逐字发送，不追加任何系统提示。注意：分辨率只支持 720p / 1080p / 4k（480p 属 1.0 系列，2.0/2.5 会被上游以「请求参数校验失败」拒绝），且该网关把参数校验放在异步执行阶段——档位写错不会在提交时报错，而是整条任务跑完才失败。
